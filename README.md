# FutureApollo765

A personal showcase built with static HTML, CSS, and JavaScript.

## Design plan

- **Home** — Keep the introduction to the public handle and interests visible in its Scratch work. Pair large typography with a monochrome orbital assembly that responds to drag and keyboard input.
- **Projects** — Present selected public Scratch projects as a looping, browsable gallery. Keep snapshots local and load an external player when a visitor chooses to play.
- **Intro** — Use the supplied recording for a brief, skippable opening. Rebuild the hand-drawn logo on a square grid with four-fold rotational symmetry. Honor reduced-motion preferences.

## Local preview

Run `python3 -m http.server 8000` in the repository and open <http://localhost:8000/>.

## GitHub Pages

The repository is named `futureapollo.github.io` under the `futureapollo765` account. Its Pages address, once enabled, is <https://futureapollo765.github.io/futureapollo.github.io/>. Relative asset URLs and hash-based navigation support that project path.

For branch publishing, choose **Settings → Pages → Deploy from a branch**, then **main** and **/ (root)**. Publishing from a private personal repository requires GitHub Pro or another eligible plan. A root site at `futureapollo765.github.io` requires a repository of that exact name. [GitHub Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)
